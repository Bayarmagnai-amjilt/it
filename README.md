# Амжилт Кибер Сургууль — МТ хичээлийн платформ

Амжилт Кибер Сургуулийн бага ангийн (1–5-р анги) мэдээллийн технологийн хичээлийн платформ.

Энэ багц нь **Үе 1А**: нэвтрэлт, анги ба сурагч, ирц, жинлэсэн дүн, Excel экспорт.
Юу хийгдсэн, юуг хэрхэн шалгахыг [docs/PHASE-1A.md](docs/PHASE-1A.md)-ээс уншина уу.

Технологи: Next.js 16 (App Router) · Tailwind CSS 4 · Supabase (PostgreSQL, Auth) · GitHub · Vercel

## 1. Суулгах заавар

Гурван үйлчилгээ хэрэгтэй. Гурвуулаа үнэгүй багцаар эхэлж болно.

| Үйлчилгээ | Үүрэг |
|---|---|
| Supabase | Өгөгдлийн сан, багшийн нэвтрэлт |
| GitHub | Кодыг хадгална |
| Vercel | Сайтыг ажиллуулна |

Дараалал чухал: эхлээд Supabase, дараа нь GitHub, эцэст нь Vercel.

### 1.1 Supabase: өгөгдлийн сан

1. [supabase.com](https://supabase.com) → **New project**. Нэр: `amjilt-it`. Database password-оо хадгалж ав. Region: Монголд ойр (Seoul, Tokyo эсвэл Singapore).
   Data API асаалттай хэвээр үлдэнэ. «Automatically expose new tables» сонголт аль ч байдалтай байж болно: SQL файл эрхүүдийг өөрөө нэг бүрчлэн олгодог.
2. **Эхлээд гадны бүртгэлийг хаа.** Authentication → Sign In / Providers → **Allow new users to sign up**-ийг унтраагаад хадгал. Асаалттай үед хэн ч өөртөө хаяг үүсгэж чадна. Тийм хаяг идэвхгүй үүсдэг тул юу ч харахгүй, гэхдээ хаалттай байх нь зөв.
3. **SQL Editor** → New query → `supabase/all_in_one.sql` файлын агуулгыг бүхэлд нь хуулж тавиад **Run**. «Success. No rows returned» гэж гарна.
   Файлд `revoke`, `drop trigger if exists` байгаа тул Supabase «destructive operation» гэж асууж магадгүй. Шинэ төсөл дээр аюулгүй, зөвшөөрнө.
   `all_in_one.sql`-ийг 2026.11.13-аас өмнө ажиллуулсан төсөл дээр зөвхөн `supabase/migrations/20261113000001_class_logos_delete.sql`, дараа нь `20261113000002_numbered_sections.sql`-ийг дарааллаар нь нэг удаа ажиллуулна (ангийн лого, анги устгах, 1А → 1-1).
4. (Сонголтоор) Туршилтын өгөгдөл: шинэ query → `supabase/seed.sql` → Run. 12 анги, 300 зохиомол сурагч, хуваарь, 4 долоо хоногийн ирц, жишээ дүн үүснэ. Эхлээд үүгээр туршихыг зөвлөж байна.
5. Багшийн хаягаа үүсгэ: Authentication → Users → **Add user → Create new user**. Имэйл, нууц үг (8-аас дээш тэмдэгт), «Auto Confirm User» чагттай.
   **Хамгийн түрүүнд үүссэн хаяг системийн эзэмшигч болно.** Дараа үүссэн хаяг бүр идэвхгүй үүснэ.
6. Гурван утгыг тэмдэглэж ав (дээд талын **Connect** товч, эсвэл Settings → API Keys):

   | Утга | Жишээ |
   |---|---|
   | Project URL | `https://abcdxyz.supabase.co` |
   | Publishable key | `sb_publishable_…` |
   | Secret key | `sb_secret_…` |

   Secret key бол өгөгдлийн сангийн бүрэн эрх. Хэнд ч бүү өг, GitHub-д бүү оруул, чатад бүү наа.

### 1.2 GitHub: код

Шинэ **Private** repository үүсгээд (README нэмэхгүй, хоосон) энэ хавтсыг оруулна.

Git суусан бол задалсан хавтас дотроо:

```bash
git init
git add .
git commit -m "Phase 1A"
git branch -M main
git remote add origin https://github.com/ТАНЫ-НЭР/amjilt-it.git
git push -u origin main
```

Git байхгүй бол GitHub Desktop ашиглах, эсвэл repository-ийн хуудсан дээр **uploading an existing file** дарж задалсан хавтасны **доторх** бүх зүйлийг чирж тавина. Вэбээр оруулахдаа хоёр зүйлийг шалга:

- `.gitignore`, `.env.example` гэх цэгээр эхэлсэн файлууд нуугдмал байдаг. Тэднийг ч оруулна.
- `app/(public)`, `app/t/classes/[id]` зэрэг хаалттай хавтсууд бүтцээрээ орсон эсэх.

`.env.local` файл болон `node_modules` хавтсыг хэзээ ч GitHub-д бүү оруул.

### 1.3 Vercel: сайт

1. [vercel.com](https://vercel.com) → **Add New → Project** → GitHub repository-гоо **Import**.
2. Framework Preset: **Next.js** (өөрөө танина). Build-ийн тохиргоог өөрчлөхгүй.
3. **Environment Variables** хэсэгт дөрвөн хувьсагч нэмнэ:

   | Нэр | Утга |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | Project URL |
   | `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Publishable key |
   | `SUPABASE_SECRET_KEY` | Secret key |
   | `PICTURE_PASSWORD_PEPPER` | 40-өөс дээш тэмдэгттэй санамсаргүй текст |

   `PICTURE_PASSWORD_PEPPER` нь сурагчдын зурган нууц үгийг хамгаална. Нууц үг үүсгэгчээр үүсгээд хадгал. Дараа нь сольвол бүх сурагч зургаа дахин сонгоно.
4. **Deploy**. Нэг хоёр минутын дараа `https://….vercel.app` хаяг гарна.

Build улайж зогсвол алдааны бичвэрийг (Build Logs-ийн улаан хэсэг) хуулаад хөгжүүлэгчид илгээнэ. [4-р хэсгийг](#4-асуудал-гарвал) үз.

### 1.4 Supabase-д сайтын хаягаа бүртгэх

Authentication → **URL Configuration**:

- Site URL: `https://таны-хаяг.vercel.app`
- Redirect URLs: `https://таны-хаяг.vercel.app/auth/callback`

Энэ нь «Нууц үгээ мартсан уу?» имэйлийн холбоос зөв хуудас руу буцахад хэрэгтэй.

### 1.5 Ажиллаж байгааг шалгах (5 минут)

1. `https://таны-хаяг.vercel.app/teacher/login` → 1.1-ийн 5-р алхмын имэйл, нууц үгээр нэвтэр. Хяналтын самбар нээгдэнэ.
2. Тохиргоо → «Багш нар» хэсэгт таны нэрийн ард **Эзэмшигч** гэж байгааг шалга.
3. Өөр хөтөч эсвэл нууц цонхоор сайтын үндсэн хаягийг нээ. Энэ бол сурагчдын хуудас. Ангиуд «хичээл эхлээгүй» гэсэн цоожтой харагдана.
4. Багшийн цонхонд аль нэг ангийн **Хичээл эхлүүлэх**-ийг дар. Сурагчийн цонхонд тэр анги 10 секундийн дотор нээгдэж, нэрс гарч ирнэ.

Дөрвүүлээ болсон бол суулгалт дууссан. Бүрэн шалгах дарааллыг [docs/PHASE-1A.md](docs/PHASE-1A.md)-д бичсэн.

## 2. Эхний тохиргоо

Туршилтын өгөгдлөөр туршсаны дараа жинхэнэ ангиудаа оруулахын өмнө сургуулийг хоосолно: SQL Editor → `supabase/reset_school_data.sql` → Run. Энэ нь анги, сурагч, ирц, дүнг бүгдийг **устгана**. Багшийн хаяг, үсгэн дүнгийн хязгаар, тохиргоо үлдэнэ.

Дараа нь багшийн сайт дээр:

1. **Тохиргоо**: хичээлийн жилээ үүсгэж, улирлуудаа огноотой нь нэм. Ирц, дүн улирлаар тооцогдоно.
2. **Ангиуд → Анги үүсгэх**: анги, бүлэг, амьтны дүрс, өнгө.
3. **Сурагч олноор нэмэх**: Excel-ийн жагсаалтаа хуулж буулгах, эсвэл `.xlsx` / `.csv` файл оруулах. Хадгалахын өмнө жагсаалтаа шалгана.
4. Анги бүрийн хуудсанд **хичээлийн хуваарь** оруул. Хяналтын самбарын «Өнөөдрийн хуваарь» үүнээс гарна.
5. **Дүн ба үнэлгээ → Үнэлгээний тохиргоо**: бүрэлдэхүүн, жин. Нийлбэр яг 100% болоход хадгална. Нэг ангид тохируулаад бусад руу хуулж болно.

## 3. Хичээл дээр хэрхэн ашиглах

| Хэзээ | Багш | Сурагч |
|---|---|---|
| Хичээл эхлэхэд | Ангийнхаа **Хичээл эхлүүлэх**-ийг дарна | Сайтын үндсэн хаягийг нээж ангиа, дараа нь нэрээ сонгоно |
| Эхний минутад | **Ирц бүртгэх**: нэвтэрсэн сурагч «Ирсэн» гэж урьдчилан тэмдэглэгдсэн байна. Зөрүүг засаад хадгална | |
| Хичээл дуусахад | **Хичээл дуусгах** | 20 секундийн дотор өөрөө гарна |

- Хичээл эхлээгүй үед сурагчдын нэрс хэнд ч харагдахгүй.
- «Хичээл дуусгах»-ыг мартсан ч Тохиргоонд заасан хугацаа (анхдагч 40 минут) өнгөрөхөд хичээл өөрөө хаагдана.
- **QR** товч проекторт зориулсан том QR код гаргана. Уншуулсан сурагч шууд ангийнхаа нэрс рүү орно.
- Зурган нууц үгийг анги бүрийн тохиргооноос асаана. 1–2-р анги 2 зураг, 3–5-р анги 3 зураг сонгоно. Мартсан сурагчийн зургийг багш профайлаас нь арилгана.
- Багш 30 минут юу ч хийхгүй бол системээс автоматаар гарна.
- **Тайлан ба Excel**: дүн, ирцийг Excel-ээр татна. Долоо хоног бүр «Нөөц хуулбар татах»-ыг дарж файлаа хадгалахыг зөвлөж байна.

## 4. Асуудал гарвал

| Юу харагдаж байна | Шалтгаан | Засах |
|---|---|---|
| Нүүр хуудсанд «Систем хараахан бэлэн болоогүй байна» | Сервер өгөгдлийн сантай холбогдож чадаагүй | Vercel-ийн 4 хувьсагчийн нэр, утгыг шалга (ялангуяа `SUPABASE_SECRET_KEY`). `all_in_one.sql` ажилласан эсэхийг шалга. Supabase төсөл зогссон (paused) эсэхийг шалга |
| Нэвтрэхэд «Таны эрх идэвхжээгүй байна» | Таны хаяг анхны хаяг биш, эсвэл идэвхгүй | SQL Editor-т: `update teachers set role = 'owner', is_active = true where email = 'таны@имэйл';` |
| Vercel-ийн build улайсан | Кодын алдаа, эсвэл сангийн шинэ хувилбар | Build Logs-ийн улаан хэсгийг хуулж хөгжүүлэгчид илгээ |
| Хувьсагч сольсон ч өөрчлөгдөхгүй | Vercel хувьсагчийг build хийх үед уншдаг | Deployments → сүүлийн мөрийн цэс → **Redeploy** |
| Долоо хоног ашиглаагүйн дараа сайт ажиллахгүй | Supabase үнэгүй багцын төслийг 7 орчим хоног идэвхгүй бол зогсоодог | Supabase Dashboard → төслөө сонгоод **Resume project**. Өгөгдөл хэвээрээ. Амралтын өмнө нөөц хуулбараа тат |
| Нууц үг сэргээх имэйл ирэхгүй | Supabase-ийн суурь имэйл үйлчилгээ туршилтынх, хязгаартай | Authentication → Emails хэсэгт өөрийн SMTP тохируулах. Яаралтай үед доорх SQL |
| Сурагчид нэрс харагдахгүй | Хичээл эхлээгүй | Ангийн **Хичээл эхлүүлэх**-ийг дар |
| Сурагч «Олон удаа буруу дарлаа» гэж гарсан | Зургаа 10 минутад 5 удаа буруу дарсан | 10 минут хүлээх, эсвэл профайлаас нь зурган нууц үгийг арилгах |

Нууц үгээ мартаад имэйл ирэхгүй бол SQL Editor-т (шинэ нууц үг, имэйлээ солиод):

```sql
update auth.users
set encrypted_password = extensions.crypt('ШинэНууцҮг2026', extensions.gen_salt('bf'))
where email = 'таны@имэйл';
```

## 5. Хөгжүүлэгчид зориулсан тэмдэглэл

### Компьютер дээрээ ажиллуулах

Node.js 20.9 буюу түүнээс шинэ хувилбар хэрэгтэй (тест ажиллуулахад 22.18+).

```bash
npm install
cp .env.example .env.local     # дөрвөн утгаа бөглөнө
npm run dev                    # http://localhost:3000
```

Анхны `npm install`-ийн дараа үүссэн `package-lock.json`-ийг commit хий. Ингэвэл Vercel яг ижил хувилбаруудыг суулгана.

### Тест

```bash
npm test                       # нэр эрэмбэлэх, огноо, ирцийн хувь, зурган нууц үг
npm run typecheck
PSQL="psql -U postgres" supabase/tests/run_local.sh
```

Сүүлийн мөр өгөгдлийн сангийн тест: эрх, RLS, нэвтрэлт, ирц, дүнгийн тооцоо. Компьютер дээрх түр зуурын PostgreSQL сан дээр ажиллана, Supabase төсөлд хүрэхгүй.

### Бүтэц

```
app/                  дэлгэцүүд (App Router)
  (public)/           сурагчийн нэвтрэлт: анги → нэр → зураг
  s/                  нэвтэрсэн сурагч
  t/                  багш
  teacher/            багшийн нэвтрэлт, нууц үг сэргээх
  present/            проекторын хуудас (QR)
  api/                Excel импорт, экспорт, нөөц хуулбар
features/             модуль бүрийн server action
components/           дэлгэцийн хэсгүүд
lib/                  тооцоо, огноо, монгол нэр, Supabase холболт, Excel
locales/mn.ts         хэрэглэгчид харагдах БҮХ бичвэр
supabase/
  migrations/         схем, функц, эрх, ангийн лого + анги устгах, үсэгтэй бүлгийг тоо болгох (5 файл)
  all_in_one.sql      дээрх файлуудыг нэгтгэсэн, SQL Editor-т зориулсан
  seed.sql            туршилтын өгөгдөл
  reset_school_data.sql   сургуулийг хоослох
  tests/              өгөгдлийн сангийн тест
tests/                нэгжийн тест
```

### Дүрэм

- Кодын нэр, тайлбар англиар. Хэрэглэгчид харагдах бичвэр зөвхөн `locales/mn.ts` дотор, монголоор.
- Сурагч өгөгдлийн сантай шууд харьцдаггүй. Сервер нууц түлхүүрээр `student_login`, `student_session` зэрэг функцийг дуудна. Сурагчийн хөтөчид зөвхөн санамсаргүй дугаартай `student_session` cookie байна.
- Багшийн бичих үйлдлүүд өгөгдлийн сангийн функцээр дамжина. Функц бүр багш тэр ангид заадаг эсэхийг өөрөө шалгана.
- `supabase/migrations/` өөрчлөгдвөл `all_in_one.sql`-ийг дахин үүсгэнэ: `bash supabase/build_all_in_one.sh`.
- Шинэ хүснэгт, функц нэмэхдээ эрхийг (`grant`) заавал бич. Supabase 2026 оны 5-р сараас шинэ хүснэгтийг автоматаар нээдэггүй болсон.
